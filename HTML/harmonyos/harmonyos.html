鸿蒙移动应用开发

第一章：标识符

变量类型

文字信息：‘字符串’类型（String）
数字信息：‘数值’类型（Number）
状态信息：‘布尔’类型（Boolean）

变量声明

使用 let 关键字声明变量。
格式：let 变量名:变量类型 = 变量值；

常量声明

使用 const 关键字声明常量。
格式：const 常量名:变量类型 = 常量值；

变量/常量命名规则

1、只能由字母、下划线（_）或美元符号（$）开头组成
2、不能以数字开头
3、不能使用关键字(const、let、class、if、for等)
4、区分大小写:Name和name是两个不同的变量
5、不能有空格，特殊符号(@ # $ - 都不行)

数组定义

数组是一种特殊的变量类型，可以存储多个值。
定义格式：let 数组名:数据类型[] = [元素1, 元素2, ...]；

数组还有下标
访问方式：数组名[下标]，下标从0开始。

对象

对象定义：对象是一种复杂的数据类型，可以存储多个属性和方法。
作用：使用class约定对象的结构和类型
定义格式：class 类名 {
    属性1:类型；
    属性2:类型；
...
}

普通函数

定义函数：使用 function 关键字定义函数。
格式：function 函数名(参数) {
    函数体
}

调用函数：函数名(实参)；
特点：一次定义，多次使用

箭头函数

定义函数：使用箭头语法定义函数。
格式：const 函数名 = (参数) => {
    函数体
};

调用函数：函数名(实参)；
特点：语法简洁，this指向定义时所在的对象

第二章：UI排版

容器组件

组件：
    column(){}
    row(){}
    stack(){}

纵向排版（换行排列）：
    column(){
        组件1
        组件2
    }

横向排版（一行排列）：
    row(){
        组件1
        组件2
    }

层叠排版（重叠排列）：
    stack(){
        组件1
        组件2
    }

一个builder只能有一个根组件，根组件可以包含多个子组件。

内容组件

组件：
    text()
    image()
    button()

文本组件：
    text("文本内容")

滚动字幕组件：
    List( ){
        ListItem( ){ }
    }
        .scrollBar(BarState.Off)

图片组件：
    image($r("app.media.XX"))

按钮组件：
    button("按钮文本", 点击事件)

属性

通用属性：
width:宽度    数值（默认单位：up）
height:高度    数值（默认单位：up）
bacgroundColor:背景颜色    色值（内置颜色或十六进制数）

文本属性：
fontSize:字体大小    数值（默认单位：up）
color:字体颜色    色值（内置颜色或十六进制数）
textAlign:文本对齐方式    left（左对齐）center（居中）right（右对齐）

图片属性：
width:宽度    数值（默认单位：up）
height:高度    数值（默认单位：up）
fit:图片适应方式    cover（裁剪）contain（缩放）fill（拉伸）none（原尺寸）

按钮属性：
width:宽度    数值（默认单位：up）
height:高度    数值（默认单位：up）
backgroundColor:背景颜色    色值（内置颜色或十六进制数）
color:字体颜色    色值（内置颜色或十六进制数）
textAlign:文本对齐方式    left（左对齐）center（居中）right（右对齐）

事件属性：
onClick:点击事件    函数
onLongClick:长按事件    函数
onHover:悬停事件    函数

布局属性：
padding:内边距    数值（默认单位：up）
margin:外边距    数值（默认单位：up）
padding和margin可以分别设置四个方向的值(如Top、Bottom、Left、Right等。不写时默认为0) 如果没写中括号，而是括号中一个值就说明四个方向的值都相同
alignItems:子组件对齐方式    start（起始对齐）center（居中对齐）end（结束对齐）
justifyContent:子组件分布方式    start（起始分布）center（居中分布）end（结束分布）spaceBetween（两端分布）spaceAround（均匀分布）
alignItems和justifyContent只能用于容器组件，且只对直接子组件生效

特殊属性：
span:跨列属性    数值
offset:偏移属性    数值
span和offset只能用于column和row组件，且span表示占用的列数，offset表示偏移的列数

边框属性：
borderWidth:边框宽度    数值（默认单位：up）
borderColor:边框颜色    色值（内置颜色或十六进制数）
borderRadius:边框圆角    数值（默认单位：up）
boederStyle:边框样式    solid（实线）dashed（虚线）dotted（点线）none（无边框）
边框属性可以同时设置四个方向的值(如Top、Bottom、Left、Right等。不写时默认为0或none)
边框属性可以在中括号中写入Width、Height、Color、Style等属性

其他属性：
id:组件标识符    字符串
class:组件分类    字符串
style:组件样式    对象
id和class可以用于组件的选择器，style可以直接在组件上设置样式

条件分支语句

if(条件){
    执行语句
}else if(条件){
    执行语句
}else{
    执行语句
}

switch(表达式){
    case 值1:
        执行语句
        break;
    case 值2:
        执行语句
        break;
    default:
        执行语句
}
