变量类型

文字信息：‘字符串’类型（String）
数字信息：‘数值’类型（Number）
状态信息：‘布尔’类型（Boolean）

变量声明

使用 let 关键字声明变量。
格式：let 变量名:变量类型 = 变量值；

常量声明

使用 const 关键字声明常量。
格式：const 常量名:变量类型 = 常量值；

变量/常量命名规则

1、只能由字母、下划线（_）或美元符号（$）开头组成
2、不能以数字开头
3、不能使用关键字(const、let、class、if、for等)
4、区分大小写:Name和name是两个不同的变量
5、不能有空格，特殊符号(@ # $ - 都不行)
